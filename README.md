# STOPAZ — Final Production Site

Standalone static-site repository for the new STOPAZ site.

## Final direction
Giving Kitchen-inspired structural/motion grammar with the completed STOPAZ visual system: white-led oversized typography, near-black, vermilion, hot orange, deep wine, large photographic fields, clipped geometry, impact-number motion, horizontal rails, responsive navigation, and section choreography.

The homepage includes the revised split hero with an 18-second Stalin cinematic loop, `STOP ANTIZIONISM` on one line, the separate `New Jewish Leadership to Meet the New Era` statement band, animated impact metrics, the clickable Antizionist Certification announcement linking to `/learn/`, and the supplied leadership/public-engagement images.

## Deployment
Upload the contents of this repository root to a new GitHub repository, GitHub Pages, Vercel, or another static host. `index.html` is the entry page. The existing STOPAZ repository is not modified by this package.

See `FINAL_QA.md` for the complete structural, responsive, motion, text, image, performance, and deployment audit.


## GitHub browser upload
This edition is intentionally fully flat: all required files are at the repository root so GitHub's browser uploader includes the entire site when all files are selected at once. The canonical Learn route in this edition is `learn.html`.
